# Ветки проекта

- `main` — основная ветка. GitHub Pages публикует её содержимое.
- Для каждой новой версии теста прыжка создай отдельную ветку `versions/jump-vNN` от актуальной `main`. Номер бери следующим после максимального опубликованного номера. Изменения и проверку выполняй в ветке версии.
- Отправляй ветку версии на GitHub. Когда пользователь просит выложить обновление на основную ссылку или выбирает версию для публикации, переноси проверенные изменения в `main` и проверяй опубликованную страницу.
- Сохраняй старые ветки версий. Откат основной версии делай новым коммитом в `main`. Проверяй локальные изменения перед переключением веток.
