# Чернила под током

Самостоятельный браузерный экшен-комикс. Механик Вера отбивается от бумажных громил в ночной типографии, перебирается на крышу и отключает реле.

Откройте `index.html` в браузере или выполните `python -m http.server 8941 --bind 127.0.0.1` из этой папки и зайдите на http://127.0.0.1:8941/.

- Enter — начать или продолжить. P — пауза. R — начать заново.
- Стрелки или A/D — движение, Пробел — прыжок.
- X — удар. Удерживайте для серии из трёх ударов.
- C — блок. Повернитесь лицом к атакующему.
- Очистите панель, подойдите к правой рамке и нажмите Пробел. После боя на крыше так же отключается реле.

Для сенсорных экранов есть экранные кнопки. Игра работает на Canvas 2D и Web Audio. Графика хранится в `assets/`.
